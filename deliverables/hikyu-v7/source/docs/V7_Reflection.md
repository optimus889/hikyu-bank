# V7 Reflection

AI assistance influenced this integration mainly by helping me identify trust boundaries and translate them into explicit contracts. I used an AI coding assistant while inspecting the supplied Saltcorn and Flowable implementation and developing the new adapters. I did not use Zapier's AI builder or add a Zapier runtime AI step. The existing Flowable classifier remained a separate runtime component, and a fresh local test classified a synthetic card-access request. Keeping those roles distinct prevents development assistance from being mistaken for a working AI automation.

The most useful design decision was to treat an external request as an unverified draft. A convenient form-to-workflow shortcut would remove the opportunity to authenticate the requester and confirm transaction ownership. The implemented handoff requires staff assignment, requester claim and a server-side ownership check before Flowable starts. Tests rejected another user's transaction and kept duplicate source events from creating another draft.

Reliability also required more control than a simple visual connection suggests. A committed support outcome and a successful external synchronization are separate facts. During the local relay contract test, an injected write failure left the business case completed while the synchronization state showed failure. A staff replay used a new delivery generation and recovered to one external record. This made recovery inspectable without depending on unverified paid replay features.

The tradeoff is additional configuration and code: signed relay requests, persistent receipts, version checks and a private authenticated integration. These controls improve traceability but require careful setup. The local tests support those implementation claims; they do not prove Google or Zapier cloud behavior. Real account authorization, live runs, plan-limit verification and external failure recovery still require owner execution before final acceptance. I therefore cannot claim measured time savings, real team experience or a completed cloud deployment.
